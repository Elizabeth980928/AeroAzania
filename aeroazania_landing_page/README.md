# AeroAzania Landing Page

A responsive HTML, CSS and vanilla JavaScript landing page inspired by the supplied reference screenshot and the AeroAzania website requirements.

## Run locally
1. Extract the ZIP file.
2. Open the `aeroazania_landing_page` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Files
- `index.html` — page structure and content
- `css/style.css` — responsive styling
- `js/main.js` — mobile navigation and active section state

## Before publishing
- Replace the illustrative aircraft photos with approved AeroAzania aircraft/CAD visuals.
- Confirm the official logo, contact email, phone number and social links.
- Review all company capability statements for factual accuracy.
- The aircraft images are illustrative and must not be presented as completed AeroAzania aircraft.
- The current contact CTA uses a mailto link. Connect a secure backend/form service before launch.

The page uses Google Fonts and remote Unsplash images, so those assets require an internet connection.
